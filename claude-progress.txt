TECHNICAL NOTES:
=================================================================

SpecSource Architecture Design:

1. **Abstract Base Class Pattern**:
   - All spec sources inherit from SpecSource ABC
   - Three abstract methods must be implemented
   - Base class provides common infrastructure (last_sync, version tracking)

2. **TaskSpec vs Task Model**:
   - TaskSpec: Lightweight spec-level representation
   - Task (from models.py): Database model with execution state
   - Conversion happens during import/sync
   - TaskSpec is immutable from source, Task tracks progress

3. **Registry Pattern**:
   - Scheme-based registration (file://, github://, jira://)
   - Factory method creates instances from URIs
   - Global singleton for convenience
   - Type-safe validation on registration

4. **Async-First Design**:
   - All SpecSource methods are async
   - Supports network I/O without blocking
   - pytest-asyncio for testing

5. **Change Detection Strategy**:
   - sync() takes dict of known tasks (spec_id -> version)
   - Compares with current state
   - Returns SyncResult with changes
   - Caller decides how to handle changes

Testing Approach:
- MockSpecSource for interface validation
- Comprehensive edge case coverage
- Async test support
- Registry isolation between tests

Using the SpecSource interface:

```python
from bob.spec_sources import get_registry, SpecSource

# Get global registry
registry = get_registry()

# Register a spec source (done by plugin at import time)
from bob.spec_sources.file import FileSpecSource
registry.register("file", FileSpecSource)

# Create a spec source from URI
source = registry.create("file://spec.yaml")

# Fetch all tasks
tasks = await source.fetch_tasks()

# Sync with known tasks
known = {"F001": 1, "F002": 2}  # spec_id -> version
result = await source.sync(known)

print(f"Added: {len(result.added)}")
print(f"Modified: {len(result.modified)}")
print(f"Removed: {len(result.removed)}")

# Mark task complete (if supported)
success = await source.mark_completed("F001", {"pr": "https://..."})
```
