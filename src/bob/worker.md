## SWE-Bench Cheap Wins (F-R7-609)

The following standing directives are injected into every worker prompt at
dispatch time by `bob.dispatch.apply_cheap_wins`:

### (A) Repo Tree

A capped (200-line) directory tree is prepended to the worker prompt to reduce
localization errors ("right file, wrong abstraction" and "wrong file").

Generated by `bob.dispatch.build_repo_tree` using `tree -L 3` with noise
exclusions (`.git`, `.venv`, `node_modules`, `__pycache__`).

### (B) STANDING DIRECTIVE — Write a Failing Repro Test First

Before editing any source file:

1. Write a failing test that captures the bug or missing behaviour.
2. Run it and confirm it is RED (fails as expected).
3. Make your edits to the source.
4. Run the test again and confirm it is GREEN (passes).

This applies to all AC kinds except structural. For structural ACs
(file_exists, grep-literal, etc.) skip this directive
(`feature.skip_repro_test: true` in the YAML overrides it at feature level).

### (C) Adaptive Edit Mode

- **Default:** String-replace (targeted edits).
- **Switch to whole-file rewrite** when: edit site count > 3 OR line span > 40.

Mode selection is computed by `bob.dispatch.compute_edit_site_metrics` from
the localizer output and logged as an `EDIT_MODE` event.

### (D) Mutation-Pass Check (Weak Test Detection)

After a worker reports test-pass, a trivial mutation (flip a constant or negate
a boolean) is applied and the test is re-run. If the test still passes, a
`WEAK_TEST_DETECTED` event is emitted and a stronger AC is required.

ICSE 2026 finding: 12–22% of "passing" patches are logically wrong because
tests under-specify behaviour. Cost: 1 extra test run per feature.

All four directives are toggleable per feature via YAML fields (defaults ON).
