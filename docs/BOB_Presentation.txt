                    SLIDE 7: ESCALATION SYSTEM
================================================================================

    Intelligent Failure Handling 🔨
    ════════════════════════════════════════════════

    When a task fails, BOB doesn't give up - it escalates intelligently.


                              Task Attempt
                                   │
                                   ▼
                    ┌──────────────────────────┐
                    │   SONNET (3 attempts)    │  Fast, $3/$15 per 1M
                    └────────────┬─────────────┘
                                 │ still failing
                                 ▼
                    ┌──────────────────────────┐
                    │    OPUS (3 attempts)     │  Capable, $15/$75 per 1M
                    └────────────┬─────────────┘
                                 │ still failing
                                 ▼
                    ┌──────────────────────────┐
                    │       DIAGNOSIS          │  Root cause analysis
                    └────────────┬─────────────┘
                                 │
                                 ▼
              ┌─────────────────────────────────────────┐
              │                                         │
              │  TOO_BIG ────────▶ Decompose subtasks  │
              │  MISSING_INFO ───▶ Research first      │
              │  WRONG_INFRA ────▶ Request user help   │
              │  BAD_ASSUMPTIONS ▶ Restructure         │
              │  NEEDS_RESEARCH ─▶ Targeted research   │
              │                                         │
              └─────────────────────────────────────────┘


    Result: Automatic recovery from most failure modes




================================================================================
                   SLIDE 8: RESEARCH-FIRST WORKFLOW
================================================================================

    Proactive Research Before Implementation 🔨
    ════════════════════════════════════════════════

    Traditional Approach:

        Code → Fail → Research → Code → Fail → Research → ... → Success

        [Expensive: Multiple Opus escalations, wasted attempts]


    BOB's Research-First:

        Research → Code → Success

        [Efficient: Research upfront, implement with knowledge]


    ┌─────────────────────────────────────────────────────────────────┐
    │  Spec Definition:                                               │
    │                                                                 │
    │  tasks:                                                         │
    │    - id: optimize-queries                                       │
    │      title: Database Query Optimization                         │
    │      description: |                                             │
    │        Optimize slow queries in production.                     │
    │        REQUIRES RESEARCH on PostgreSQL optimization.            │
    │      research_required: true           ◄── Mark for research    │
    │      research_queries:                 ◄── Guided queries       │
    │        - "PostgreSQL EXPLAIN ANALYZE patterns"                  │
    │        - "Index optimization for time-series data"              │
    │                                                                 │
    └─────────────────────────────────────────────────────────────────┘


    Benefits:
    • Proactive, not reactive
    • Domain-specific query guidance
    • Findings persist across sessions
    • Avoids expensive Opus escalations

    Concurrent Task Processing 🔨
    ════════════════════════════════════════════════

    BOB builds a dependency graph and runs independent tasks in parallel:


    ┌─────────────────────────────────────────────────────────────────┐
    │                                                                 │
    │  Dependency Graph:              Execution Timeline:             │
    │                                                                 │
    │       ┌─────────┐                                               │
    │       │ setup   │              Time ──────────────────────▶     │
    │       └────┬────┘                                               │
    │            │                   ┌────────┐                       │
    │     ┌──────┴──────┐            │ setup  │                       │
    │     │             │            └────┬───┘                       │
    │  ┌──▼──┐       ┌──▼──┐              │                           │
    │  │ api │       │ ui  │         ┌────▼───┐  ┌───────┐            │
    │  └──┬──┘       └──┬──┘         │  api   │  │  ui   │  PARALLEL  │
    │     │             │            └────┬───┘  └───┬───┘            │
    │     └──────┬──────┘                 │          │                │
    │         ┌──▼──┐                ┌────▼──────────▼───┐            │
    │         │tests│                │      tests        │            │
    │         └─────┘                └───────────────────┘            │
    │                                                                 │
    └─────────────────────────────────────────────────────────────────┘


    $ bob run --parallel 3     # Run up to 3 tasks concurrently


    Benefits:
    • Faster overall completion
    • Better resource utilization
    • Each task gets isolated session
    • Failures don't block independent work

================================================================================
                     SLIDE 15: GETTING STARTED
================================================================================

    Quick Start Guide 🔨
    ════════════════════════════════════════════════


    1. INSTALL
    ──────────────────────────────────────────────

       $ git clone https://github.com/yye00/bob.git
       $ cd bob
       $ ./init.sh
       $ export ANTHROPIC_API_KEY='your-key'


    2. CREATE PROJECT
    ──────────────────────────────────────────────

       $ bob init
       $ bob project create my-app ./workspace file://spec.yaml
       $ bob project use my-app


    3. DEFINE SPEC
    ──────────────────────────────────────────────

       # spec.yaml
       tasks:
         - id: setup
           title: Project Setup
           priority: critical
         - id: feature-1
           title: First Feature
           depends_on: [setup]


    4. RUN
    ──────────────────────────────────────────────

       $ bob run                 # Start autonomous development
       $ bob status              # Check progress
       $ bob logs --follow       # Watch in real-time
